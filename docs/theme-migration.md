## 文件与数据归属

- `themes/songminghe/`：主题模板、图标、CSS、JS、播放器及第三方许可。
- `content/`：沿用正式内容，仅新增最新文章页面。
- `assets/`：沿用正式头像、技术封面和图表源文件。
- `data/blog.json`：歌单、首页置顶和站点运行起点。
- `static/music/`、`static/media/`：用户音乐与封面、背景图片及来源说明。
- `static/` 的旧分页目录：保留静态跳转，避免旧地址失效。
- `layouts/single.markdown.md`：沿用正式 Markdown 导出模板。
- 原 Stack 子模块在迁移验收期间暂时保留，2026-10-08 按用户要求移除；当前个人主题不依赖它。需要恢复原版时，从 Git 历史检出旧版本并初始化对应子模块。

Demo 的后台预览服务、对比页、构建产物和备份不进入正式主题。

## 兼容处理
